# Чек-лист организационных мер (Роскомнадзор / 152-ФЗ)

Технические меры в приложении закрывают часть требований. То, чего **нельзя** сделать кодом, перечислено ниже. Отметьте пункты до выкладки в production.

## Обязательно до запуска с реальными пользователями

- [ ] Подать **уведомление в Роскомнадзор** об обработке персональных данных (если школа ещё не в реестре операторов).
- [ ] Назначить **ответственного** за организацию обработки ПДн (приказ).
- [ ] Утвердить внутренние документы: политика, положения, модель угроз, инструкции для сотрудников.
- [ ] Проверить у **юриста** тексты в приложении (`Политика`, согласия по целям, пользовательское соглашение) — в seed стоит пометка «Шаблон».
- [ ] Убедиться, что **база и бэкапы** размещены на территории РФ (хостинг PocketBase / VPS).
- [ ] Зафиксировать договор с хостером: конфиденциальность, место хранения, сроки удаления.
- [ ] Подготовить порядок **уведомления об инциденте** (утечке) в Роскомнадзор в течение 24 часов и субъектам — по закону.
- [ ] Для несовершеннолетних: процесс получения согласия законного представителя отражён в оферте/договоре обучения (не только в приложении).

## После выкладки приложения

- [ ] Выложить `pb_hooks` и миграции, **перезапустить PocketBase**.
- [ ] Открыть `/admin/registration-qr` → **Сменить** токен приглашения (seed-токен в production отвергается).
- [ ] Задать `WEB_PUSH_RELAY_SECRET`, VAPID-ключи, HTTPS.
- [ ] Проверить security headers на nginx (`deploy/security-headers.conf`).
- [ ] Пройти сценарий: регистрация по QR → отдельные галочки → отзыв необязательного согласия → выгрузка данных → удаление аккаунта.
- [ ] Убедиться, что в `audit_logs` появляются записи `consent.accepted` / `consent.revoked` / `account.deleted` / `account.data_exported`.

## Рекомендуется

- [ ] Регламент доступа сотрудников к админке PocketBase (отдельные учётки, без общего пароля).
- [ ] Регулярный пересмотр списка целей обработки и сроков хранения.
- [ ] Журнал обращений субъектов ПДн (запросы на доступ/удаление вне приложения).
- [ ] Обучение сотрудников правилам работы с персональными данными.
